## 一、屏幕适配：横屏 → 竖屏

将游戏分辨率从 `800×600` 改为 `390×844`（iPhone 14 竖屏比例）。

**核心认知**：使用 `Phaser.Scale.FIT` 模式，游戏画面等比缩放适配不同屏幕，不会拉伸变形。点阵/网格型游戏对比例敏感，FIT 是最安全的选择。

**配置位置**：[js/config.js](../../js/config.js) → `CONFIG.GAME.WIDTH / HEIGHT`

## 三、程序化纹理生成

用 `Graphics` API 绘制并用 `generateTexture()` 烘焙成纹理，无需外部图片：

- `btn` — 圆角矩形（按钮背景）
- `block` — 绿色方块
- `circle` — 橙色圆形
- `dot` — 灰色小圆点（点阵用，半径 0.5px）
- `arrow` — 基础箭头（杆 + 三角尖，长度 = 点阵一格 25px）
- `segment` — 线段（无箭头的直杆，长度 = 一格）

**关键认知**：
- `generateTexture('key', w, h)` 把 Graphics 内容存到全局纹理管理器，跨场景复用
- `fillRect(0, 0, w, h)` 和 `generateTexture('key', w, h)` 的宽高通常一致，前者画多大，后者截多大
- Text 不是纹理——Text 是运行时实时渲染的，适合动态内容（得分 popup、标签）

## 四、点阵（Dot Matrix）

14 列 × 24 行的圆点矩阵，用 `Container` 容器管理。

**Container 的优势**：
- 容器内坐标是相对的，容器放哪整体到哪
- 不需要手动计算每个点的绝对坐标来居中
- 移动整个点阵只需一句 `container.setPosition(x, y)`

**坐标体系理解**：
- x 轴 → 从左到右
- y 轴 → 从上到下（屏幕坐标 y 向下为正）
- z 轴（模拟）→ 垂直屏幕指向观众，`setDepth()` 值越大越靠前
- `add` 的顺序 = 隐式 z（后加的盖在前面），`setDepth()` = 显式 z

## 五、箭头线（ArrowLine）游戏对象

### 5.1 概念

**基础箭头**（arrow）：有三角尖，一格长，指向右。靠 `setAngle()` 旋转实现四方向。

**线段**（segment）：无尖直杆，一格长。用于箭头线的中间段。

**箭头线**：基础箭头 + N 个线段组成的路径，沿点阵格子走。最终定义为：**一个基础箭头 + 若干线段**，没有线段时退化为纯基础箭头。

### 5.2 数据结构

```js
// 一条路径：起点 (startCol, startRow)，每段描述方向和步数
{ startCol, startRow, path: [{ dir: 'right', count: 3 }, { dir: 'down', count: 2 }] }
// → 起点向右 3 格，再向下 2 格，末端为基础箭头
```

### 5.3 文件组织

独立为 `js/objects/ArrowLine.js`。加载顺序：`config.js → ArrowLine.js → 场景文件`。

### 5.4 贪吃蛇式移动

**核心思路**：不移动图像本身，每步"销毁 + 重生"。

每步（50ms 间隔）：
1. 快照所有段的 `(x, y, angle)`
2. 全部销毁
3. 头（images[0]）在新位置重生（前进一格）
4. 身体[i] 在前一段的旧位置重生（含角度）
5. 尾离开屏幕 → 整线销毁

**为什么是"生成"而不是"移动"**：
- `setAngle` 的 tween 会让线段在转弯时产生旋转过渡（链条断裂感）
- 纯生成没有过渡动画，角度从旧位置直接继承，拐弯自然

### 5.5 碰撞系统

**边注册表**：`ArrowLine._edgeMap`（静态 Map），key = 无向边（两个端点排序），value = 占据该边的 ArrowLine。

飞行每一步检查：头要进入的边是否被其他箭头线占据。

**碰撞行为**：
| 角色 | 效果 |
|------|------|
| 撞人的（自己） | 立刻变红，永久保持；`alive=false` 不再响应点击 |
| 被撞的（对方） | 闪烁 0.5s 后恢复常态 |

## 六、坐标系小结

| 维度 | 含义 | 控制方式 |
|------|------|---------|
| x | 左右（0 → 宽） | `image.x` / 构造参数 x |
| y | 上下（0 → 高，向下为正） | `image.y` / 构造参数 y |
| z（隐式） | 前后，后 add 的在上 | `add` 顺序 |
| z（显式） | 前后，数字越大越靠前 | `setDepth(n)` |
