## 二、术语体系定型

经过反复讨论，沉淀了以下术语：

| 术语 | 含义 | 示例 |
|------|------|------|
| **箭头阵** | 管理所有箭头线 + 点阵边界（未实现） | — |
| **箭头线** | Step 的有序数组 | — |
| **步（Step）** | 最小单元，一条有向边 | `Step {start, end, dir, angle, texture}` |
| **尾巴点** | 路径起始格点 | `(col, row)` |
| **路径** | 有向向量数组（压缩） | `[{right,3}, {down,2}]` |
| **有向向量** | 路径的成员，朝一个方向连走 count 步 | `{dir:'right', count:3}` |
| **步序列** | 底层，展开后 | `['right','right','right','down','down']` |
| **头尖点** | 箭头尖端格点，可由尾巴点+路径算出 | `(5,4)` |

### 层级关系

```
箭头阵（未实现）
  └── 箭头线 = Step 的有序数组
        └── 步（最小单元）
```

### 描述 vs 存储

- **描述方式**：尾巴点 + 路径（压缩，用于构造）
- **存储方式**：步序列 Step[]（展开，用于所有操作）

## 三、Step 对象 — 数据结构重构

**旧代码问题**：`_edges`、`_steps`、`images` 三套平行数组，通过索引隐式关联。维护困难，容易出错。

**新设计**：Step 升格为头等对象，一条箭头线就是一个 Step 数组。所有信息封装在 Step 内：

```
Step {
    startCol, startRow   — 起点
    endCol, endRow       — 终点
    dir                  — 方向
    angle                — 旋转角度
    texture              — 'arrow' | 'segment'
    edgeKey              — 无向边 key
    centerCol, centerRow — 中心点（getter）
}
```
