# 游戏玩法介绍

## 这是什么游戏

一个**排程清线**解谜游戏。

棋盘是一张点阵，上面停着若干条箭头线。每条线只能朝一个固定方向走。你的任务很简单：**按正确的顺序依次点击它们，让所有线安全离开棋盘。** 一条也别撞到另一条，撞了就废了。

---

## 规则

### 你面对的

- 一张点阵棋盘，圆点铺在上面
- 盘面上停着一组箭头线。每条线有头有尾，头（箭头端）指向它唯一能走的方向
- 线上可能有些空位——空位不是bug，是谜题留的呼吸空间

### 操作

- 点击任意一条箭头线 → 它开始朝头的方向飞行
- 线飞行时，头前移一格、尾收缩一格，像虫子爬
- 一次只能有一条线在飞。飞的过程中点其他线没反应

### 碰撞

- 飞行的线如果碰上了另一条停着的线 → **撞废**
- 撞废的线永久变红，退回原位，再也不能动
- 一条线废了，这关就不可能全清了

### 过关

- 所有线安全飞出棋盘 → 过关

---

## 解谜思路

线不能互相碰。先飞哪条、后飞哪条，会决定后面线能不能找到一条干净的路离开。

你要做的就是：**观察每条线的位置和方向，推理出谁挡着谁，然后排出正确的发射顺序。** 排对了，全清过关。排错了，撞废重来。

---

## 例子

### 第一关：横扫

```
•→•→•→•→•
•→•→•→•→•
•→•→•→•→•
```

所有线都是右向的平行线，互不挡路。**随便怎么点都能全清。** 这一关用来熟悉操作。

### 后续关卡：蛇形

```
•→•→•→•→•
        ↓
•←•←•←•←•
↓
•→•→•→•→•
```

线互相交叉了。如果你先点最上面那条，它飞的时候可能挡住中间那条的路——中间那条就撞了。

你得找出正确的顺序。这就是谜题。
