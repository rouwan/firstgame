# 箭头阵生成方案（最新版）—— 递归分治填空法

## 核心思想

将一次性生图改为**多轮递进填空**——每一轮瞄准上一轮留下的空区域，当成独立小棋盘继续生图，直到所有空区域都是单点。

## 算法流程

```
generateAll():
    allLines = []
    alreadyPlaced = {}          // 已建线的 label 集合（所有轮次）

    loop:
        // 第一轮在全棋盘，后续在空区域内
        batch = 在空闲格点中按序列逆序构造，constraint=alreadyPlaced
        allLines.push(...batch)

        regions = dotMatrix.getEmptyRegions()        // BFS 找连通空区
        fillable = regions.filter(r => r.size > 1)  // 过滤单点
        if fillable.length == 0: break

        for each region in fillable:
            在 region 的空闲格点中按序列逆序构造新线
            allLines.push(...)
```

## 关键约束

- **每轮建线时**：`alreadyPlaced` = 所有前轮已建的线。本轮建线不能指向已建线。
- **空区域游走**：随机游走和邻居查询限制在当前空区域的格点集合内。
- **标签**：所有轮次完成后，按顺序 1..N 统一编号。

## 发射顺序

轮次天然分层——第 1 轮线先飞，第 2 轮线后飞。因为第 2 轮线建线时已知前轮线的位置，flyDir 避开了它们。

## DotMatrixNew 新增

- `getEmptyRegions()` → BFS 找所有空区域，返回 `[{cells: [{col,row},...], size}]`
- `_regionFilter` — 可选 Set，过滤 getAvailablePoints/getAvailableNeighbors 只在该区域内

## 与旧版对比

| 维度 | 序列逆序构造（旧） | 递归分治填空（新） |
|------|-----------------|-----------------|
| 覆盖率 | 约 30-50% | 目标 90%+ |
| 轮次 | 1 轮 | 多轮（通常 2-3 轮） |
| 线数 | 算法决定 | 几乎铺满 |
| 空区域 | 仅统计，不修复 | 主动递归填空 |
